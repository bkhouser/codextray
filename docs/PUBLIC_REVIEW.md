# Public-source review — October 31, 2026

Baseline: private v0.2.0, followed by the reviewed public candidate, designated 1.0.0 for the first stable release. Scope includes all app/Core sources, Windows persistence/UI/startup, process and JSONL integration, API cost access, tests, dependencies/runtime, CI, export/package tooling, documentation and Git/publication boundaries.

## Corrected findings

| Finding | Impact | Remediation |
| --- | --- | --- |
| Session-local singleton did not serialize shared per-user settings across Windows sessions | A stale instance could recreate a removed billing credential | Lifetime exclusive per-user data lock acquired before reading or editing saved state; regression verifies exclusivity and crash-restart file behavior |
| Canceled/failed initialization could leave a session reader running with startup marked consumed | Leaked/inconsistent startup state for Core API callers | Initialization failures terminate/cancel/drain the session with bounded cleanup; four startup failure/cancellation regressions |
| Exporter included any nonignored untracked files and only checked leaf links | Accidental local/private files or linked ancestor contents could enter publication | Tracked/staged candidates only, explicit forbidden file paths, ancestor reparse-point checks, no original Git directory/history |
| Self-contained package instructions omitted .NET redistribution notices | Runtime license notices could be lost in binary redistribution | Package script includes actual restored runtime license and third-party texts, executable/ZIP checksums and app license |
| Public-facing setup did not state the full privilege scope of an Admin key | Users could mistake read-only app behavior for a restricted credential | Explicit local setup/README warning; ordinary Codex monitoring requires no API key |

Earlier v0.2.0 protocol/cancellation, tracker, parser, disposal and UI findings remain covered by regression tests. See REVIEW_0.2.0.md and SECURITY_REVIEW.md for provenance. No new credential or live account data was inspected for this review.

## Public-source boundary

The prepared repository has independent initial history and a verified GitHub noreply author identity. No original private author-email metadata, historical usage reports, raw logs, encrypted state, installed executable, tools or build output is imported. MIT attribution is preserved. An internal integration design is excluded. README artwork uses synthetic values generated by a test fixture.

## Validation and limits

The 1.0.0 source suite passed 127 tests locally, including Windows STA/UI and DPAPI checks. Workflow syntax is checked with checksum-verified actionlint; Verify and CodeQL are commit-pinned, scoped to minimum permissions, and use no signed-in Codex account or Admin key. A scheduled check detects when the pinned .NET runtime falls behind Microsoft's servicing metadata. Current toolchain/runtime metadata and NuGet advisory checks are refreshed during preparation. The final export is independently built, tested, packaged and scanned; results are recorded in SMOKE_TEST_REPORT.md.

No blocking source findings remain from this review after remediation. This is not a penetration-test certification or upstream Windows/Codex audit. Hosted CodeQL/CI execution, GitHub security settings, signing and clean-machine/high-DPI/multiple-monitor/screen-reader acceptance require the corresponding environment/publication decision. Their unexecuted status must remain explicit. Source publication and advertising an unsigned binary release are separate decisions.
